## Mesure

- Google Search Console : requêtes prioritaires + performance par page (impressions, clics, CTR, position moyenne).
- Pages indexées : vérifier après chaque déploiement via sitemap / Inspection d'URL.
- Request indexing : uniquement pour quelques URL nouvelles ou modifiées importantes ; pour le reste, sitemap + maillage interne.

## Divers

- Ne pas noindexer de pages par erreur.
- Ne pas supprimer de métadonnées existantes lors des prochaines éditions.
