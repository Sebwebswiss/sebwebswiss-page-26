# SebWebSwiss V2 — Update 02 (Mobile hamburger menu)

This ZIP contains the full current set of project files, including every prior update and the new responsive hamburger menu.

## Install in WSL

1. Download this ZIP to Windows Downloads.
2. Keep the existing `npm run dev` terminal open.
3. In a second WSL terminal, run:

```bash
cd ~/web/web_stranice/sebwebswiss2026/sebwebswiss-v2
unzip -o /mnt/c/Users/sebas/Downloads/sebwebswiss-v2-update-02-mobile-menu.zip
```

4. Refresh http://localhost:3000 with Ctrl+Shift+R.

Do not run a second `npm run dev` process. If the server is stopped, run it once from the project folder.
